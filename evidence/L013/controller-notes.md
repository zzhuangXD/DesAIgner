# 控制器补充

规范由控制器按照本 Skill 指定的官方 URL 实际获取后送入模型，并非依赖模型记忆。生成模型自报自己没有 WebFetch 工具，指的是其隔离请求没有联网工具，不代表没有收到已获取的规范。

初次生成后，控制器再次获取新鲜规范，用同一模型和仅此 Skill 对实际 HTML 执行独立的源码审查。修正包括安全区、动画属性、SVG 缩放、作品选择的 ARIA 状态、持续显示的“正在读取”反馈、日期格式化和品牌翻译保护。原始源码、规范、审查请求、发现和精确差异均保存。

修正后已重新执行 1440、390、320 像素真实浏览器检查，作品切换及键盘激活通过，无文档横向溢出、资源加载或控制台错误。web-design-guidelines 的角色始终是约束与审查，基础视觉由模型自行生成。
