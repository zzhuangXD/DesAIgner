CAPABILITY CASES / L013 — L015

三种能力，
三个真正适合的现场。

审查页面、打磨工作台、读懂设计系统。每个 Skill 回到自己的适用场景，每个网页解释它影响了什么，并保留提示词、源码与实际验证。

场景化能力演示 · 不作同题排名
013

VERCEL / WEB-DESIGN-GUIDELINES

从能看，到能用。

一个工作坊报名表：定位缺失标签、不可键盘提交、错误反馈和缩放限制。保留审查前输入，提供可填写的修复版。

打开报名页审查案例 ↗
主要能力

网页规范与可用性审查

建议你试

空白提交 → 看字段提示与焦点；用 Tab / Enter 完成填写。

014

IBELICK / BASELINE-UI

让界面回到工作本身。

创意工作室的素材审核台：清理层级、间距、数字和状态。检索、查看、通过与撤回均可操作，空结果也有明确出口。

打开素材审核工作台 ↗
主要能力

产品界面基线与细节整理

建议你试

搜索素材 → 打开详情 → 确认通过；再从已通过中撤回。

015

STITCH SKILLS / EXTRACT-DESIGN-MD

把视觉变成可复用的语言。

接手一家虚构书店的源码：提取颜色角色、字体、间距、组件和断点，发现近似颜色漂移，输出可下载 DESIGN.md。

打开设计系统解剖案例 ↗
主要能力

从源码提取并记录设计系统

建议你试

选择色板看来源与关联部件；切到“复用与漂移”查看延展卡片。

怎么理解这里的“Skill 做到了什么”？

这些是本地 Agent 实际读取并应用指定 Skill 后制作的教学案例。Skill 提供规则或工作流，基础视觉、演示输入和实现代码的贡献分别说明。没有隔离模型上下文、无 Skill 基线或统计评估，因此不用于判断三个仓库的绝对强弱。L015 使用无需外部服务的源码提取 Skill，未调用 Stitch 云端。
